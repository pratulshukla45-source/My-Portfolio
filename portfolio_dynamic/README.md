# Pratul Shukla — Python Backend Developer Portfolio

A responsive portfolio built with HTML, CSS and JavaScript. It includes resume-based skills, work experience, education, project highlights, interactive skill filters, scroll reveal animations, animated role text, a dark/light theme switch, active section navigation, a reading-progress bar, and contact links.

## Run locally
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy with GitHub Pages
1. Push the project files to the `main` branch of your portfolio repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Wait for the Pages deployment to finish.

## Before publishing
- Verify the phone number, email and LinkedIn URL. The phone number is displayed publicly and uses a click-to-call link.
- Project cards link to the live Prayash website or the GitHub profile. Individual repository links have not been guessed because the resume does not contain project URLs.
- Gaongram work may be company-owned and should only be linked directly if public sharing is permitted.
- The Appointment Booking API repository should be security-reviewed before linking directly to its source.
- Add a downloadable resume only after confirming the PDF is the final public version.
